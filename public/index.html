Conexión con Google Health API

Configura el acceso para traer los datos de tu banda inteligente

Para conectar tu banda inteligente (Fitbit / Pixel Watch) vinculada a tu cuenta de Google:

  1. Crea un proyecto en Google Cloud Console.
  2. Habilita la Google Health API.
  3. Crea credenciales ID de cliente de OAuth (Aplicación web).
  4. Agrega como URI de redireccionamiento autorizado: http://localhost:3000/oauth2callback

¿Aún no has configurado la Google Cloud Console?

Puedes usar el Modo Demostración para explorar el dashboard de inmediato con métricas realistas y gráficos interactivos completos de pasos, ritmo cardíaco y sueño.

Activar Modo Demostración
1
Ir a Google Cloud Console

Accede a console.cloud.google.com con la misma cuenta de Google vinculada a tu banda.

2
Habilitar Google Health API

En el menú lateral ve a APIs y Servicios > Biblioteca, busca Google Health API y haz clic en Habilitar.

3
Configurar Pantalla de Consentimiento OAuth

En Pantalla de consentimiento, elige "Externo", completa tu correo y añade tu propio email como "Usuario de prueba".

4
Crear Credenciales OAuth

En Credenciales > Crear credenciales > ID de cliente de OAuth:

  • Tipo: Aplicación web
  • URI de redireccionamiento: http://localhost:3000/oauth2callback
5
Conectar

Pega el Client ID y Client Secret en la pestaña "Conectar API" y pulsa "Conectar con Google Health".
